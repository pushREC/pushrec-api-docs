# Contributing to Trigger.dev

## Overview

The Contributing page on Trigger.dev's documentation explains how to participate in the project's development. According to the page:

> "Go to our GitHub repository and open an issue or a pull request. We are always looking for contributors to help us improve Trigger.dev."

## Ways to Contribute

The project welcomes contributions across multiple areas:

- **Bug reporting** - Identify and document issues
- **Feature suggestions** - Propose enhancements
- **Documentation** - Improve guides and references
- **Code development** - Write and improve functionality
- **Code review** - Evaluate pull requests
- **Localization** - Translate the application
- **Community engagement** - Share and promote the project
- **Feedback** - Provide user insights
- **And more** - Additional unspecified contributions

## Getting Started

Contributors should:

1. Visit the [GitHub repository](https://github.com/triggerdotdev/trigger.dev)
2. Open an issue to discuss changes or report problems
3. Submit pull requests for proposed modifications

The project maintains an [open-source license](https://github.com/triggerdotdev/trigger.dev?tab=Apache-2.0-1-ov-file#readme) and welcomes participation from the community at all skill levels.
