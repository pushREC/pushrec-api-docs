## Main Content

### Overview
This community-developed Vite plugin from @cptCrunch_ enables seamless integration between SvelteKit and Trigger.dev. It allows developers to use their SvelteKit functions directly within Trigger.dev projects.

### Features
- Use SvelteKit functions directly in Trigger.dev tasks
- Automatic function discovery and export
- TypeScript support with type preservation
- Works with Trigger.dev V3
- Configurable directory scanning

### Prerequisites
- Setup a project in SvelteKit
- Ensure TypeScript is installed
- Create a Trigger.dev account
- Create a new Trigger.dev project

### Setup Instructions

The documentation references viewing a setup guide on npm:

```bash
npm i triggerkit
```

**Installation package:** triggerkit (available on npm)
