# Run Tests - Trigger.dev Documentation

## Overview

The documentation page explains how to use Trigger.dev's dashboard to test tasks before running them in production.

## Key Information

**Location**: Access the test feature via the "Test" page in the dashboard's side menu.

**Main Capability**: Users can execute test runs for any task across different environments without deploying to production.

## Testing Workflow Steps

The interface guides users through six numbered steps:

1. **Task Selection** - Choose which task to test
2. **Payload Configuration** - Include test payload or metadata
3. **Advanced Options** - Configure machine size, queue assignment, or execution delay
4. **History Access** - Review and select from previous test runs
5. **Template Saving** - Store current test configuration for future use
6. **Execution** - Run the test
