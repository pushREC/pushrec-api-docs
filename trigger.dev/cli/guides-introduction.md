# Frameworks, Guides and Examples - Trigger.dev

## Overview

"A growing list of guides and examples to get the most out of Trigger.dev."

Trigger.dev is an open source background jobs framework enabling developers to write reliable workflows in plain async code, supporting long-running AI tasks, complex background jobs, and AI agent construction with built-in queuing, automatic retries, and real-time monitoring capabilities.

---

## Frameworks

The platform supports integration with five major JavaScript frameworks:

- **Bun** - JavaScript runtime setup guide
- **Next.js** - Full-stack React framework integration
- **Node.js** - Server-side JavaScript runtime
- **Remix** - Full-stack web framework
- **SvelteKit** - Svelte-based web application framework
