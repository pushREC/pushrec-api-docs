## YouTubeTranscriptApi Class

The main entry point for all transcript operations.

### Constructor

```python
from youtube_transcript_api import YouTubeTranscriptApi

ytt_api = YouTubeTranscriptApi(
    http_client=None,      # Optional: custom requests.Session
    proxy_config=None      # Optional: proxy configuration object
)
```

**Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `http_client` | `requests.Session` | `None` | Custom HTTP session for cookies, headers, certificates |
| `proxy_config` | `ProxyConfig` | `None` | Proxy configuration (WebshareProxyConfig or GenericProxyConfig) |

### Methods

#### `fetch(video_id, languages=['en'], preserve_formatting=False)`

Retrieves the transcript for a single video.

```python
transcript = ytt_api.fetch(
    video_id="dQw4w9WgXcQ",
    languages=['de', 'en'],
    preserve_formatting=True
)
```

**Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `video_id` | `str` | Required | YouTube video ID (NOT the full URL) |
| `languages` | `list[str]` | `['en']` | Language codes in priority order |
| `preserve_formatting` | `bool` | `False` | Keep HTML tags like `<i>`, `<b>` |

**Returns:** `FetchedTranscript` object

**Raises:**
- `TranscriptsDisabled` - No transcripts available
- `NoTranscriptFound` - No matching language found
- `RequestBlocked` - YouTube blocked the request

---

#### `list(video_id)`

Lists all available transcripts for a video.

```python
transcript_list = ytt_api.list("dQw4w9WgXcQ")
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `video_id` | `str` | YouTube video ID |

**Returns:** `TranscriptList` object

## TranscriptList Class

Container for all available transcripts of a video. Iterable.

### Methods

#### `find_transcript(languages)`

Finds transcript by language, preferring manually created over generated.

```python
transcript = transcript_list.find_transcript(['de', 'en'])
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `languages` | `list[str]` | Language codes in priority order |

**Returns:** `Transcript` object

---

#### `find_manually_created_transcript(languages)`

Finds only human-created transcripts.

```python
transcript = transcript_list.find_manually_created_transcript(['en'])
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `languages` | `list[str]` | Language codes in priority order |

**Returns:** `Transcript` object

**Raises:** `NoTranscriptFound` if no manual transcript matches

---

#### `find_generated_transcript(languages)`

Finds only auto-generated transcripts.

```python
transcript = transcript_list.find_generated_transcript(['en'])
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `languages` | `list[str]` | Language codes in priority order |

**Returns:** `Transcript` object

**Raises:** `NoTranscriptFound` if no generated transcript matches

## Transcript Class

Represents metadata about a transcript (not the actual content).

### Properties

| Property | Type | Description |
|----------|------|-------------|
| `video_id` | `str` | YouTube video ID |
| `language` | `str` | Human-readable language name |
| `language_code` | `str` | ISO language code (e.g., 'en') |
| `is_generated` | `bool` | True if auto-generated by YouTube |
| `is_translatable` | `bool` | True if can be translated |
| `translation_languages` | `list` | Available translation target languages |

### Methods

#### `fetch()`

Downloads the actual transcript content.

```python
fetched = transcript.fetch()
```

**Returns:** `FetchedTranscript` object

---

#### `translate(language_code)`

Creates a translated version of this transcript.

```python
translated_transcript = transcript.translate('de')
translated_data = translated_transcript.fetch()
```

**Parameters:**

| Parameter | Type | Description |
|-----------|------|-------------|
| `language_code` | `str` | Target language code |

**Returns:** New `Transcript` object (call `.fetch()` to get content)

## FetchedTranscript Class

Contains the actual transcript data. Implements list-like interface.

### Properties

| Property | Type | Description |
|----------|------|-------------|
| `video_id` | `str` | YouTube video ID |
| `language` | `str` | Human-readable language name |
| `language_code` | `str` | ISO language code |
| `is_generated` | `bool` | True if auto-generated |
| `snippets` | `list` | List of transcript segments |

### List Operations

```python
# Iterate over snippets
for snippet in fetched_transcript:
    print(snippet['text'])

# Access by index
first = fetched_transcript[0]
last = fetched_transcript[-1]

# Get length
count = len(fetched_transcript)
```

### Snippet Structure

Each snippet is a dictionary:

```python
{
    'text': 'Hello world',    # Transcript text
    'start': 0.0,             # Start time in seconds
    'duration': 2.5           # Duration in seconds
}
```

### Methods

#### `to_raw_data()`

Converts to list of dictionaries.

```python
data = fetched_transcript.to_raw_data()
# Returns: [{'text': '...', 'start': 0.0, 'duration': 2.5}, ...]
```

**Returns:** `list[dict]`

## Formatters

Convert transcripts to various output formats.

### Available Formatters

```python
from youtube_transcript_api.formatters import (
    JSONFormatter,
    TextFormatter,
    WebVTTFormatter,
    SRTFormatter,
    PrettyPrintFormatter
)
```

### Usage

```python
formatter = JSONFormatter()
output = formatter.format_transcript(transcript, indent=2)
```

### Formatter Classes

#### JSONFormatter

Outputs JSON format.

```python
formatter = JSONFormatter()
json_str = formatter.format_transcript(transcript, indent=2)
```

#### TextFormatter

Outputs plain text (just the transcript text, no timestamps).

```python
formatter = TextFormatter()
text = formatter.format_transcript(transcript)
```

#### SRTFormatter

Outputs SubRip subtitle format.

```python
formatter = SRTFormatter()
srt = formatter.format_transcript(transcript)
```

Output example:
```
1
00:00:00,000 --> 00:00:02,500
Hello world

2
00:00:02,500 --> 00:00:05,000
This is the transcript
```

#### WebVTTFormatter

Outputs WebVTT format for web video players.

```python
formatter = WebVTTFormatter()
vtt = formatter.format_transcript(transcript)
```

#### PrettyPrintFormatter

Human-readable formatted output.

```python
formatter = PrettyPrintFormatter()
pretty = formatter.format_transcript(transcript)
```

### Custom Formatter

Create your own formatter by inheriting from `Formatter`:

```python
from youtube_transcript_api.formatters import Formatter

class CustomFormatter(Formatter):
    def format_transcript(self, transcript, **kwargs) -> str:
        # Process single transcript
        lines = []
        for snippet in transcript:
            lines.append(f"[{snippet['start']}] {snippet['text']}")
        return "\n".join(lines)

    def format_transcripts(self, transcripts, **kwargs) -> str:
        # Process multiple transcripts
        return "\n---\n".join(
            self.format_transcript(t, **kwargs) for t in transcripts
        )
```

## Proxy Configuration

Required for production deployments where YouTube blocks cloud IPs.

### WebshareProxyConfig

For Webshare.io residential proxy service:

```python
from youtube_transcript_api.proxies import WebshareProxyConfig

proxy_config = WebshareProxyConfig(
    proxy_username="<username>",
    proxy_password="<password>",
    filter_ip_locations=["de", "us"]  # Optional: filter by country
)

ytt_api = YouTubeTranscriptApi(proxy_config=proxy_config)
```

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `proxy_username` | `str` | Yes | Webshare username |
| `proxy_password` | `str` | Yes | Webshare password |
| `filter_ip_locations` | `list[str]` | No | Country codes to filter IPs |

### GenericProxyConfig

For any HTTP/HTTPS proxy:

```python
from youtube_transcript_api.proxies import GenericProxyConfig

proxy_config = GenericProxyConfig(
    http_url="http://user:pass@proxy.example.com:8080",
    https_url="https://user:pass@proxy.example.com:8080"
)

ytt_api = YouTubeTranscriptApi(proxy_config=proxy_config)
```

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `http_url` | `str` | Yes | HTTP proxy URL with credentials |
| `https_url` | `str` | Yes | HTTPS proxy URL with credentials |

## Custom HTTP Client

Override HTTP behavior with a custom session:

```python
from requests import Session

http_client = Session()
http_client.headers.update({
    "Accept-Encoding": "gzip, deflate",
    "User-Agent": "Custom Agent"
})
http_client.verify = "/path/to/certfile"

ytt_api = YouTubeTranscriptApi(http_client=http_client)
```

## Error Handling

### Exception Classes

| Exception | Description |
|-----------|-------------|
| `TranscriptsDisabled` | Video has transcripts disabled |
| `NoTranscriptFound` | No transcript matches language criteria |
| `NoTranscriptAvailable` | No transcripts exist for video |
| `RequestBlocked` | YouTube blocked the request |
| `IpBlocked` | Your IP is banned by YouTube |
| `VideoUnavailable` | Video doesn't exist or is private |
| `TooManyRequests` | Rate limit exceeded |

### Example Error Handling

```python
from youtube_transcript_api import YouTubeTranscriptApi
from youtube_transcript_api._errors import (
    TranscriptsDisabled,
    NoTranscriptFound,
    VideoUnavailable
)

ytt_api = YouTubeTranscriptApi()

try:
    transcript = ytt_api.fetch("VIDEO_ID")
except TranscriptsDisabled:
    print("This video has transcripts disabled")
except NoTranscriptFound:
    print("No transcript found for requested languages")
except VideoUnavailable:
    print("Video is unavailable or private")
except Exception as e:
    print(f"Error: {e}")
```

## Rate Limits and Restrictions

1. **No Official Rate Limits:** YouTube doesn't publish rate limits for this undocumented API

2. **IP Blocking:** YouTube actively blocks cloud provider IPs (AWS, GCP, Azure). Use residential proxies for production.

3. **Age-Restricted Content:** Currently unavailable due to broken cookie authentication

4. **Geographic Restrictions:** Some videos may be blocked in certain regions. Use proxy with appropriate location.

5. **Best Practices:**
   - Add delays between requests (1-2 seconds)
   - Use rotating residential proxies
   - Handle errors gracefully with retries
   - Cache results to reduce requests
