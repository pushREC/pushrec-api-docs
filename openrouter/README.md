OpenRouter is a unified API for accessing 200+ LLM models from multiple providers including OpenAI, Anthropic, Google, Meta, and more.

## Quick Start

```bash
curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "anthropic/claude-3.5-sonnet",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
```

## Key Features

- **200+ Models**: Access Claude, GPT-4, Gemini, Llama, and more
- **OpenAI-Compatible**: Drop-in replacement for OpenAI SDK
- **Smart Routing**: Automatic fallbacks, provider selection
- **Model Variants**: `:free`, `:extended`, `:nitro`, `:thinking`, `:online`
- **Observability**: Built-in broadcast to Langfuse, Langsmith, Datadog
- **Zero Data Retention**: Optional ZDR for privacy
