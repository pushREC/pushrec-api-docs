# Organization Management

## Overview

OpenRouter organizations enable team collaboration through shared credits, centralized API key management, and unified usage tracking across members.

## Key Features

### Organization Setup

- Create organizations via Settings > Preferences
- Requires verified email address
- Switch between personal and organization contexts using the organization switcher

### Credit Management

- Shared credit pool accessible to all members
- Only administrators can purchase credits or access billing information
- Manual credit transfers from personal accounts available through support

### API Key Management

- All members can create keys; each member manages only their own keys
- Any member can use keys created by others
- Administrators view and manage all organization keys
- All usage bills to the organization's credit pool

### Activity Tracking

- Organization activity feeds display all member usage metadata
- Filtering available by specific API key
- Note: The system currently shows all member activity when in organization context

## Administrative Controls

Administrators have exclusive access to:

- Provider and privacy settings configuration
- Member role management (Admin or Member roles)
- Billing and payment method setup

## Limitations & Important Details

- Maximum 10 organization members (contact support for exceptions)
- Personal accounts cannot convert to organizations
- Members see usage metadata but no prompts or responses
- Leaving an organization revokes access to shared resources
- Users can belong to multiple organizations simultaneously
