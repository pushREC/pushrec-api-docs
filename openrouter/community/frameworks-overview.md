# Frameworks and Integrations Overview

Integrate OpenRouter using popular frameworks and SDKs. Complete guides for OpenAI SDK, LangChain, PydanticAI, and Vercel AI SDK integration.

## Supported Frameworks and SDKs

- **OpenAI SDK** - Use the official OpenAI SDK with OpenRouter
- **LangChain** - Python and JavaScript integration with LangChain framework
- **PydanticAI** - Python integration using PydanticAI framework
- **Vercel AI SDK** - Next.js integration with Vercel AI SDK

## Additional Integrations

- **Effect AI SDK** - Integrate using the Effect AI SDK
- **Arize** - Observability and tracing for Python and JavaScript
- **LiveKit** - Voice AI agents with LiveKit Agents framework
- **Langfuse** - Observability and tracing for Python applications
- **Mastra** - Unified AI model access through Mastra
- **Xcode** - Apple Intelligence integration in Xcode 26
- **Zapier** - AI-powered automation with 8000+ apps
