# Thinking Variant

## Overview

The `:thinking` variant activates "extended reasoning capabilities for complex problem-solving tasks," enabling models to perform deeper analysis through step-by-step reasoning.

## Implementation

To use this feature, append `:thinking` to your model identifier:

```json
{
  "model": "deepseek/deepseek-r1:thinking"
}
```

## Key Benefits

According to the documentation, this variant is "particularly useful for complex tasks that benefit from chain-of-thought reasoning." It allows models to conduct more comprehensive problem analysis rather than providing direct answers.
