# Container Registry Reference

Validated on 17 Nov 2025 • Last edited on 17 Nov 2025

The DigitalOcean Container Registry (DOCR) is a private Docker image registry that lets you store and manage private container images. DOCR integrates natively with Docker environments and DigitalOcean Kubernetes clusters.

### The DigitalOcean API[](#the-digitalocean-api)

You can use the Container Registry API to [create, delete, and manage your container registry](/reference/api/digitalocean/#tag/Container-Registry). If you create more than one registry under a Professional plan, use the [Container Registries API](/reference/api/digitalocean/#tag/Container-Registries) to manage them.

### The DigitalOcean Command Line Client, doctl[](#the-digitalocean-command-line-client-doctl)

[`doctl`](https://github.com/digitalocean/doctl) is the command-line interface for the DigitalOcean API. It supports most of the same actions available in the API and DigitalOcean Control Panel.

[`doctl`](https://github.com/digitalocean/doctl) supports managing container registries from the command line. See the [`doctl registry` documentation](/reference/doctl/reference/registry/) or use `doctl registry --help` for more information. If you create more than one registry under a Professional plan, use the [`doctl registries`](/reference/doctl/reference/registries/) to manage them.
