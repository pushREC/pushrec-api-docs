I'd be happy to help you with skills! The `/skill` command needs additional information to work properly.

Here are the common ways to use it:

**To run a specific skill:**
```
/skill-name [optional arguments]
```

**Available skills include:**
- `/copywriting` - Marketing and sales copy assistance
- `/deep-research` - Comprehensive research tasks
- `/linkedin-copywriting` - LinkedIn content creation
- `/email-copywriting-kb` - Email copywriting with knowledge base
- `/facebook-ad-copy` - Facebook ad creation
- `/hooks` - Create engaging hooks
- `/landing-pages` - Landing page development
- `/persona-engine` - Persona development
- `/prompt-creator` - Create detailed prompts
- And many more...
