I'd be happy to help you with skills! Could you please specify what you'd like to do?

Here are some common skill-related requests:

1. **Create a new skill** - I can help you build a custom skill for a specific task
2. **List available skills** - See what skills are currently available
3. **Run a specific skill** - Execute one of the available skills (use `/skill-name`)
4. **Learn about skills** - Understand how skills work in Claude Code

Which would you like to do?

If you want to run a specific skill, you can use the format `/skill-name`. For example:
- `/commit` - Create a git commit
- `/copywriting` - Help with copywriting tasks
- `/deep-research` - Perform deep research on a topic
