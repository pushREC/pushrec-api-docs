'd be happy to help you with skills! The `/skill` command needs more information to work properly.

Here are some ways you can use skills:

**To create a new skill:**
```
/skill-creator
```

**To run an existing skill:**
```
/skill-name [optional arguments]
```

For example, if you have a skill called "commit", you'd run:
```
/commit
```

**To see available skills:**
You have many skills available including:
- `/copywriting` - For marketing and sales copy

- `/deep-research` - Conduct deep research
- `/email-copywriting-kb` - Email copywriting knowledge base
- `/facebook-ad-copy` - Facebook ad copy generation
