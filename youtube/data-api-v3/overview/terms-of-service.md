# YouTube API Services Terms of Service

*Last Updated: 2025-08-28*

## Overview

This legal document governs access and use of YouTube API Services. The agreement comprises multiple documents including the Terms of Service, Developer Policies, YouTube Guidelines, Google Software Principles, and YouTube Terms.

## Key Definitions

**YouTube API Services** encompass the YouTube API services (Data API, Reporting API), documentation, sample code, API Data, and assigned credentials.

**API Client** refers to websites or applications developed by users that access YouTube API Services.

**Developer Policies** are required compliance guidelines located on the YouTube Developer Site.

**YouTube Confidential Information** includes information provided by YouTube excluding independently developed data or publicly available information.

## Core Requirements

### Permitted Use
Users must comply with the Agreement when accessing YouTube API Services and only use them as documented. YouTube may suspend access for violations and has no obligation to provide the services.

### User Authorization
Users must be of legal age, not barred by applicable law, and may accept terms on behalf of employers (with proper authority).

### Legal Compliance
All users and API Clients must comply with applicable laws and not violate regulations, engage in deceptive practices, or breach export controls.

### Privacy and Security
- API Clients must publish privacy policies describing data collection and use
- Users must maintain reasonable security controls protecting YouTube data and user information
- Compliance with all privacy laws including GDPR and COPPA is mandatory

## Content Upload Requirements

### Mandatory Notices
Upload screens must display: "By clicking 'upload,' you certify that content complies with YouTube Terms of Service...please be sure not to violate others' copyright or privacy rights."

### Channel Attribution
API Clients enabling uploads must offer users the option to upload to their own YouTube channels with equal prominence to uploading elsewhere.

### Children's Content
- Child-directed API Clients cannot implement write-based actions on YouTube
- Non-child-directed clients must enable "Made for Kids" designation before upload or notify users to declare content as such on YouTube

## Brand and Intellectual Property

### Brand Usage
YouTube grants non-exclusive, revocable, limited licenses to display YouTube Brand Features only according to Branding Guidelines. All goodwill inures to YouTube's benefit.

### Ownership
YouTube retains all rights to API Services, Brand Features, API Data, and derivative works. Users retain ownership of their API Clients excluding YouTube Property.

### Attribution Requirements
All API Clients must provide proper attribution per YouTube Branding Guidelines. YouTube may terminate brand licensing at any time.

## Liability and Warranties

### No Warranties
"THE YOUTUBE API SERVICES ARE PROVIDED 'AS IS' AND 'AS AVAILABLE'" with no guarantees of uninterrupted, timely, secure, or error-free operation.

### Limited Liability
YouTube's total liability is capped at amounts paid in the prior six months or $1,000, whichever is higher. YouTube is not liable for lost profits, indirect damages, or consequential damages.

### Content Disclaimer
YouTube hosts content but accepts no responsibility for availability, accuracy, usefulness, safety, or legality of user-submitted materials.

## Indemnification

Users must indemnify YouTube against third-party claims arising from API Client use, Agreement violations, alleged infringement, or user-provided content. YouTube may assume defense control and users cannot settle claims without YouTube's written consent.

## Modifications and Termination

### Service Changes
YouTube may modify or discontinue API Services without notice. Backward-incompatible changes require six months' notice. Special "Subject API Services" receive one year's notice from February 10, 2017.

### Termination Rights
YouTube may suspend or terminate access at any time for breaches, misconduct, court orders, or conduct creating liability. Users may terminate anytime by discontinuing use.

### Post-Termination Obligations
Upon termination, users must immediately delete all API Data and YouTube Confidential Information and certify deletion in writing upon request.

## Special Provisions

### Quotas
YouTube may set usage quotas and users cannot exceed or circumvent restrictions.

### Monitoring
YouTube may monitor, review, and audit API Clients and user access anytime without notice to verify compliance and ensure quality.

### Change of Control
Users must notify YouTube within 15 calendar days of ownership changes. Failure to obtain approval within 45 days results in automatic project termination.

### Non-Assert Agreement
For three years post-termination, users agree not to assert patent infringement claims against YouTube relating to API Services accessed, unless YouTube initiates patent claims first.

## Publicity and Public Statements

YouTube may use company names, product names, and logos in marketing materials, case studies, and customer lists without prior approval. Users cannot claim YouTube partnership or endorsement without written approval.

## Governing Law

California law applies (excluding conflict rules). All disputes litigate exclusively in Santa Clara County federal or state courts. Causes of action must commence within one year or are permanently barred.

## Additional Notices

### EU Compliance
EU users must comply with the EU User Consent Policy.

### Regional Variations
Different Terms of Service versions exist for Americas, APAC, EMEA, and Russia regions.
