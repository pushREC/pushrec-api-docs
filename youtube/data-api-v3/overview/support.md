- `youtube-api`
- `youtube-data-api`
- `youtube-v3-api`

## Getting Help

### For Technical Questions
1. Search existing Stack Overflow questions first
2. Check the official documentation
3. Post a new question with relevant tags
4. Include code samples and error messages

### For Bugs
1. Check the Issue Tracker for existing reports
2. File a new bug with reproduction steps
3. Include API request/response details

### For Feature Requests
1. Submit through the Issue Tracker
2. Describe the use case
3. Explain why existing features don't meet needs
