# System-Managed Reports Documentation

## Overview

System-managed reports are automatically generated by YouTube for eligible content owners. Unlike standard reports, these do not require creating a reporting job via the `jobs.create()` method.

## Key Characteristics

- **Automatic Generation**: YouTube automatically generates these reports for content owners
- **Cannot Be Modified**: Content owners cannot create, modify, or delete system-managed jobs
- **Includes Actual Revenue**: Provides actual (not estimated) revenue data for eligible partners
- **Special Access Required**: Only available to content owners meeting specific eligibility criteria

## Available System-Managed Reports

YouTube generates approximately 5 types of system-managed reports:

| Report Type | Description |
|-------------|-------------|
| Ad Revenue (Raw) | Detailed advertising revenue data |
| Ad Revenue (Summary) | Aggregated advertising revenue |
| Asset Ad Revenue | Revenue tied to specific claimed assets |
| Claims Data | Information about content claims |
| Subscription Revenue | YouTube Premium and channel membership revenue |

## Accessing System-Managed Reports

### Listing Jobs

To include system-managed reports in job listings:

```
GET https://youtubereporting.googleapis.com/v1/jobs?includeSystemManaged=true
```

### Identifying System-Managed Jobs

Jobs have a `systemManaged` boolean property:
- `true` - Job is system-managed (auto-generated by YouTube)
- `false` or absent - Standard user-created job

### Listing Report Types

To include system-managed report types:

```
GET https://youtubereporting.googleapis.com/v1/reportTypes?includeSystemManaged=true
```

## Retrieval Process

1. **List jobs** with `includeSystemManaged=true` parameter
2. **Identify system-managed jobs** by checking `systemManaged: true`
3. **List reports** for the job using `jobs.reports.list()`
4. **Download reports** using the `downloadUrl` from report metadata

## Financial Data Notes

System-managed reports provide actual revenue figures rather than estimates:
- More accurate than estimated revenue in standard reports
- Subject to finalization periods (typically end of month)
- Required for official financial reconciliation

## Eligibility Requirements

Access to system-managed reports typically requires:
- YouTube Partner Program membership
- Content owner account setup
- Appropriate revenue sharing agreements
- Compliance with YouTube monetization policies

## Important Limitations

- Cannot schedule or unschedule system-managed reports
- Report types are determined by YouTube based on account eligibility
- Data availability depends on account status and content type
- Some reports may only be available to specific partner tiers
