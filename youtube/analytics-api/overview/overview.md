# YouTube Analytics and Reporting APIs - Documentation Overview

## Core Purpose

The YouTube Analytics and Reporting APIs enable developers to "retrieve YouTube Analytics data to automate complex reporting tasks, build custom dashboards, and much more."

## Two API Approaches

**Reporting API**: Designed for applications needing to retrieve and store bulk reports with filtering, sorting, and data mining capabilities.

**Analytics API**: Supports real-time, targeted queries for generating custom reports based on user interactions.

## Key User Groups

### Channel Owners

Access viewing statistics and trends through:
- Bulk reports
- Targeted query reports

### Content Owners

YouTube Partner Program members can aggregate analytics data across all linked channels using both report types.

## Data Analysis Capabilities

The APIs use dimensions and metrics to measure user activity and aggregate data. Users can analyze:
- Video view frequency
- Average viewer watch duration
- Demographic breakdowns (age, gender)
- Geographic viewing patterns

## Available Resources

**Sample Requests**: Documented examples for channel owners and content owners with API Explorer integration

**Reporting Groups**: Custom collections of up to 500 channels, videos, playlists, or assets for performance analysis

**Code Samples**: Available in Apps Script, Java, JavaScript, Python, and Ruby
